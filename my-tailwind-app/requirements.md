# Website Requirements

## Core purpose

Build a web application for prompts that helps both technical and non-technical users discover, review, and apply prompts for AI tools like Gemini, ChatGPT, Claude, and similar.

## Main features

- User dashboard for prompt browsing and quality checks.
- Admin dashboard for managing prompt content, images, videos, categories, and SEO tags.
- Prompt experiences for audio editing, document editing, and image generation.
- Clear navigation for prompt categories and example outcomes.
- Support for AI tools, prompt editing, and prompt validation.

## Technology stack

- Frontend: React, Vite, Tailwind CSS, Ant Design, React Router
- Backend: Node.js, Express, CORS, router modules
- Development: npm workspaces, separate frontend/backend packages
