Templates folder

Open the static templates in a browser to preview UI designs without running the React app.

Files:
- `admin.html` — Admin dashboard mockup and prompt usage table
- `prompts.html` — Prompt gallery and actions (Copy/Edit)
- `user.html` — User dashboard mockup and recent activity
- `styles.css` — Shared styles

To preview locally, open the files directly in a browser or serve the `frontend/templates` folder using a static server (e.g., `npx serve frontend/templates`).
