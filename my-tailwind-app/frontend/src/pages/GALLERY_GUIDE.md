## 🔧 Difficulty Levels

### Beginner (Green badge)
- Simple, straightforward prompts
- Works with most AI tools
- Quick results
- Examples: "Write an email", "Enhance a photo"

### Intermediate (Blue badge)
- Requires some context/setup
- May need prompt refinement
- Better results with parameters
- Examples: "Refactor code", "Analyze trends"

### Advanced (Red badge)
- Complex multi-step prompts
- Requires experimentation
- May need custom adjustments
- Examples: "Build system architecture", "Data science project"

## ⭐ Rating System

### How Ratings Work
- **Scale**: 1-5 stars
- **Based on**: User feedback and effectiveness
- **Count**: Number of ratings received

### Using Ratings
Higher rated prompts = More reliable results

Example:
```
⭐⭐⭐⭐⭐ (4.9 / 1,240 reviews)  ← Most reliable
⭐⭐⭐⭐ (4.2 / 450 reviews)      ← Good, fewer users
⭐⭐⭐ (3.5 / 120 reviews)        ← Experimental
```

- Open tool manually

- Try different search terms
- Browse by category
- Check difficulty filter
- See featured/trending

### Issue with Result?
- Check prompt was copied fully
- Read the full prompt text
- Try with different AI tool
- Read before/after example
